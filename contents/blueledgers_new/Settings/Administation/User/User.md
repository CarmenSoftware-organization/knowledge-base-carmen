**User**

**User** คือ การสร้างรายชื่อผู้มีสิทธิ์เข้าใช้งานให้กับระบบ ดังนี้

สามารถเข้าใช้งานโดย Click “<img src="assets/media/image1.png"
style="width:0.20344in;height:0.155in" />” เพื่อเข้าสู่หน้าต่างตั้งค่า

<img src="assets/media/image2.png"
style="width:6.76806in;height:2.08403in" />

1.  **ขั้นตอนการสร้าง User**

    1.  Click “User” เพื่อเข้าสู่หน้าต่างการสร้างสิทธิ์การใช้งาน

    2.  Click “New” เพื่อสร้าง User

    3.  ระบุข้อมูลสำหรับสร้าง User

        - Login Name ชื่อ (User) สำหรับใช้ Login

        - First Name ชื่อผู้ใช้งาน (จำเป็นต้องระบุ)

        - Middle Name ชื่อกลาง (ถ้ามี)

        - Last Name นามสกุล (จะระบุหรือไม่ก็ได้)

        - Email อีเมล์ (จำเป็นต้องระบุ)

        - Title รายละเอียดงาน (ระบุหรือไม่ก็ได้)

    4.  Click สัญลักษณ์
        “<img src="assets/media/image3.png" style="width:0.20005in" />”
        เพื่อเปิดใช้งาน Business Unit ให้กับ User ที่สร้าง

<img src="assets/media/image4.png"
style="width:3.24496in;height:2.9493in" />

5.  Click “Save” เพื่อบันทึกข้อมูล

    - เมื่อบันทึกข้อมูลแล้วระบบจะแสดงหน้าต่างให้ทำการ Set Password

    - ระบุรหัสผ่าน และยืนยังอีกครั้งให้ทำการ Click “Save” หรือ “Cancel” เพื่อยกเลิก
      หรือ Click “<img src="assets/media/image5.png"
      style="width:0.13335in;height:0.15001in" />” Automatically
      Generate a Password เพื่อเลือกให้ระบบสร้างรหัสผ่านให้

<img src="assets/media/image6.png"
style="width:2.37009in;height:1.85693in" />

- Click “Save” เพื่อบันทึกรหัสผ่าน

6.  หากต้องการแก้ไขรหัสผ่าน Click “<img src="assets/media/image7.png"
    style="width:0.20749in;height:0.15719in" />” เพื่อ set Password

7.  Click “Edit” เพื่อแก้ไขรายละเอียด หรือเพื่อระบุแผนก

<img src="assets/media/image8.png"
style="width:2.38462in;height:2.31501in" />

8.  Click “<img src="assets/media/image9.png"
    style="width:0.16668in;height:0.16668in" />” เพื่อระบุ Department ให้กับ
    User

<img src="assets/media/image10.png"
style="width:2.43816in;height:2.36111in" />

- ระบุ Department

- กำหนด Role ให้กับ User

- กำหนด Location ให้ User มองเห็น จากนั้น Click “Save”

<img src="assets/media/image11.png"
style="width:3.62728in;height:3.7475in" />
